# VisionInspect 用户手册

版本：1.1.0

---

## 1. 软件简介

VisionInspect 是一套**工业视觉检测上位机**软件。它从相机采集图像，执行检测（**工件缺陷检测** 或 **人脸检测**），实时统计结果，并将结果通过 TCP 上报给 PLC 或上位服务。

支持两种采集源：**虚拟相机**（无硬件也能演示）与**真实摄像头**（Media Foundation 采集本机摄像头）。

---

## 2. 运行环境

- Windows 或 Linux
- 已部署 Qt 运行库（或使用 Qt Creator 直接运行）

## 3. 启动

双击 `VisionInspect.exe`，或命令行运行：

```
VisionInspect.exe
```

启动后进入主界面：中央为实时画面区，右侧为控制面板，底部为日志窗口。

---

## 4. 界面说明

### 4.1 顶部工具栏
- **相机下拉框**：选择相机类型——**虚拟相机** 或 **真实摄像头 (MediaFoundation)**。
- **开始采集**：打开相机并启动检测流水线。
- **停止**：停止采集与检测。

### 4.2 中央画面区
实时显示相机画面。启用检测后，显示**叠加标记的结果图**：

- **工件检测模式**：绿框=OK（工件无缺陷）、红框=NG（检出缺陷）、红圈=缺陷位置。
- **人脸检测模式**：绿色框标出检出的人脸。

### 4.3 控制面板（右侧）

**检测参数**
| 参数 | 默认 | 含义 |
|---|---|---|
| 启用检测 | 开 | 勾选后执行检测、计入统计并显示标记图 |
| 检测模式 | 工件检测 | **工件检测（缺陷/OK-NG）** 或 **人脸检测（肤色 Blob）** |
| 工件阈值下限 | 160 | 大于等于该灰度视为工件亮区（工件模式） |
| 缺陷阈值上限 | 40 | 小于等于该灰度视为暗缺陷（工件模式） |
| 缺陷最小面积 | 4 | 小于该面积的连通域视为噪声忽略 |
| NG 缺陷面积上限 | 200 | 缺陷总面积超过则判 NG |
| NG 缺陷数量上限 | 0 | 缺陷数量超过则判 NG（0=有缺陷即 NG） |

修改后点击**应用参数**生效（检测模式也在此处生效）。

**结果上报（TCP）**
- 服务器地址、端口：目标 PLC/服务器的地址。
- **连接** / **断开**：手动控制连接；连接异常时软件会自动重连（间隔 3 秒）。
- 状态：显示"未连接 / 已连接 / 连接失败"。

**检测统计**
- 工件模式：OK / NG / 总数 / 良率实时累计。**清零**重置计数。
- 人脸模式：显示当前帧**检出人脸数**。

### 4.4 日志（底部）
记录流水线启停、相机、TCP、每帧检测结果等运行信息，最多保留 1000 条。

### 4.5 状态栏
- **FPS**：当前采集帧率。
- **图像**：当前图像分辨率。

## 5. 操作流程（推荐）

1. 启动程序。
2. **选择相机**：想用自己摄像头选"真实摄像头 (MediaFoundation)"，否则用"虚拟相机"。
3. 在 **结果上报** 区填写服务器地址（如 `127.0.0.1:8000`），点击**连接**（可选）。
4. 在 **检测模式** 选择"工件检测"或"人脸检测"，点击**应用参数**。
5. 点击 **开始采集**。
6. 观察中央画面与统计面板：
   - 真实摄像头 + 人脸检测：可看到自己实时画面并被绿框标出人脸。
   - 虚拟相机 + 工件检测：约 50% 概率出现 NG 红框。
7. 需要时调整 **检测参数** 并点击 **应用参数**。
8. 使用 **停止** 结束，或在右侧**清零**重置统计。

> **提示**：工件检测算法针对"亮色圆盘工件 + 暗缺陷"，用在真实摄像头画面上通常会判 NG（因为画面里没有工业工件）——这是正常的。要看真实画面有意义的检测，请切换到**人脸检测模式**。

## 6. 上报协议说明

软件每次检测完成后，通过 TCP 发送一帧数据：

```
[0xAA 0x55] [载荷长度:4字节 LE] [JSON载荷] [CRC16:2字节]
```

JSON 载荷示例：

```json
{
  "type": "inspection_result",
  "ok": false,
  "work_found": true,
  "defect_count": 2,
  "defect_area": 78.0,
  "timestamp_ms": 1767772800000,
  "work_x": 110, "work_y": 110, "work_w": 120, "work_h": 120
}
```

| 字段 | 含义 |
|---|---|
| ok | true=OK，false=NG |
| work_found | 是否定位到工件 |
| defect_count / defect_area | 缺陷数量 / 总面积 |
| work_x/y/w/h | 工件包围盒 |
| timestamp_ms | 检测时刻毫秒时间戳 |

CRC16 覆盖「长度 + 载荷」两段，接收方可据此校验数据完整性。

## 7. 常见问题

**Q：画面不显示？**
A：确认已点击"开始采集"；检查"启用检测"勾选状态；确认相机下拉已选择。

**Q：用真实摄像头时全是 NG？**
A：正常。工件检测算法针对"亮色圆盘工件"，真实环境画面不满足。请切换到**人脸检测模式**即可看到人脸框。

**Q：如何看到 NG 结果？**
A：虚拟相机 + 工件检测下约 50% 概率生成缺陷帧，等待数秒即可看到 NG 红框；也可调低"缺陷阈值上限"提高检出灵敏度。

**Q：TCP 连接不上？**
A：确认目标地址/端口正确、服务端已监听；软件会自动重连。可用 `nc -l 8000` 或自写 Socket 服务端接收测试。

**Q：想接入工业相机 SDK？**
A：在 `src/camera` 新增 `CameraInterface` 实现类，调用工业相机 SDK 采集，在 `MainWindow::startPipeline` 中切换即可。
